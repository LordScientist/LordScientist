## 🌌 The Vibe

I like things that are a little bit science, a little bit art. Some days that's a dashboard, some days it's a voice assistant on Kali Linux, some days it's a sketch, a history rabbit hole, or a novel I can't put down.

I read history to see how people were wrong at scale, philosophy to learn how to doubt well, and novels to practise being someone else for a while. Code is where all three get to argue.

## 💭 Thoughts From the Edge of What I Know

> *Every program is a small argument about how the world works, and every bug is the world disagreeing.*

> *Knowledge is a lantern, not a map. It lights only the next few steps, and the dark behind you isn't gone, just unexplored.*

> *We teach machines to think, and in the attempt discover how little we understood our own thinking.*

> *A well-asked question is already half a bridge. Stand at the edge of what you know, and build outward.*

> *Every language is a map someone drew of what mattered to them. Teach a machine one, and you hand it a worldview.*

> *Memory is the first code ever written: a story we compile and run again each time we remember.*

> *A character is a question that learned to walk.*

**Questions I'm sitting with**

- When a machine learns to lie convincingly, did we teach it deception, or did it simply find it?
- If a language is how people think, what changes when software finally speaks it back to them?
- What do we owe the minds we build, and what do they owe the ones who built them?
